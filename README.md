## Projects

- [**spanish-spoken-digit-recognition**](https://github.com/AlbertoGM1812/spanish-spoken-digit-recognition): recognizes spoken digits in Spanish from audio features (MFCCs and spectral statistics) with Random Forest and KNN.
- [**bio-inspired-optimization**](https://github.com/AlbertoGM1812/bio-inspired-optimization): genetic algorithms, genetic programming, particle swarm, ant colony and bee colony, ending with an ant colony solver for logistics routes with time windows.
- [**sargassum-image-classification**](https://github.com/AlbertoGM1812/sargassum-image-classification): image classification of sargassum levels on beaches with a fine-tuned EfficientNet-B0 (school Kaggle competition).
- [**image-processing-toolkit**](https://github.com/AlbertoGM1812/image-processing-toolkit): desktop app with classic image processing: Fourier, segmentation, morphology, filters and more.
- [**machine-learning-fundamentals**](https://github.com/AlbertoGM1812/machine-learning-fundamentals): regression, Naive Bayes, K-NN, feature selection and K-Means exercises from my machine learning courses.
- [**financial-simulator**](https://github.com/AlbertoGM1812/financial-simulator): web app to register a company's monthly results and project its future with a deterministic forecast and Monte Carlo simulation (Next.js, TypeScript, Supabase).
